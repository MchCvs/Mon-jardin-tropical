# Mon Jardin Tropical

Calendrier lunaire et conseils de jardinage tropical adaptés à La Réunion.

## Fonctionnalités
- 🌙 Calendrier lunaire en temps réel
- 🌺 Plantes recommandées par phase
- ✅ Gestion des tâches
- 📮 Données sauvegardées localement

## Phases Lunaires

Le calendrier affiche les huit phases astronomiques :
- **Nouvelle Lune**
- **Premier croissant**
- **Premier quartier**
- **Lune gibbeuse croissante**
- **Pleine Lune**
- **Lune gibbeuse décroissante**
- **Dernier quartier**
- **Dernier croissant**

L'affichage indique également le pourcentage éclairé et le sens du cycle.

Les conseils de jardinage et les recommandations de plantes restent organisés selon quatre catégories traditionnelles :
- **Nouvelle Lune** : Semis, plantations
- **Lune Croissante** : Récoltes, taille
- **Pleine Lune** : Observation, traitement
- **Lune Décroissante** : Désherbage, élagage

Ces conseils relèvent de traditions de jardinage lunaire ; leur efficacité agronomique n'est pas établie scientifiquement.

Le calcul astronomique est effectué localement avec la bibliothèque
[SunCalc](https://github.com/mourner/suncalc), sous licence BSD-2-Clause.
Voir le fichier `LICENSE-SUNCALC.txt`.

## Utilisation
1. Ouvre https://mchcvs.github.io/Mon-jardin-tropical/
2. Installe l'appli (menu → Installer)
3. Consulte les conseils du jour selon la phase lunaire
4. Gère tes tâches de jardinage
