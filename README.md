# Mon Jardin Tropical

Calendrier lunaire et conseils de jardinage tropical adaptés à La Réunion.

## Fonctionnalités
- 🌙 Calendrier lunaire en temps réel
- 🌺 Plantes recommandées par phase
- ✅ Gestion des tâches
- 📮 Données sauvegardées localement

## Phases Lunaires
- **Nouvelle Lune** : Semis, plantations
- **Lune Croissante** : Récoltes, taille
- **Pleine Lune** : Observation, traitement
- **Lune Décroissante** : Désherbage, élagage

## Utilisation
1. Ouvre https://mchcvs.github.io/Mon-jardin-tropical/
2. Installe l'appli (menu → Installer)
3. Consulte les conseils du jour selon la phase lunaire
4. Gère tes tâches de jardinage
